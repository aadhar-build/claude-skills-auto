# claude-skills-auto

Claude agent skills built by aadhar-build. Each skill lives at `<skill-name>/SKILL.md`.

| Skill | Status | What it does |
| --- | --- | --- |
| [book-author-videos](book-author-videos/SKILL.md) | On trial (since Nov 2026) | Daily pick from your reading list with three verified videos of the author talking about that book (~10, 20-45, 60+ min), plus feedback and learning-note capture scored for depth. |

## Install

Copy a skill folder into your Claude skills directory (for Claude Code, `~/.claude/skills/<skill-name>/`), or upload it as a skill on claude.ai. Then ask Claude to set it up; the skill's setup section asks what it needs.
